# MoonComm 项目申报书

## 项目简介

MoonComm 是一个使用 MoonBit 开发的轻量、确定性集体通信算法仿真与性能估算工具。项目面向分布式计算、AI 训练和并行程序开发场景，通过统一的拓扑、调度与成本模型，帮助开发者理解并比较不同集体通信算法在不同 rank 数量、消息规模和链路条件下的行为。

项目不依赖 GPU、NPU 或集群环境。用户可以在普通计算机上输入通信操作、拓扑参数、链路延迟和带宽，获得算法通信步骤、正确性检查结果、关键路径与预计耗时，并比较候选算法。

## 解决的问题

Ring、Tree、Direct 等集体通信算法具有不同的启动延迟、通信轮数和带宽利用特点。现有学习资料通常只展示公式或固定动画，完整仿真工具又往往依赖大型框架。MoonComm 希望提供一个可嵌入、可测试、易于运行的 MoonBit 原生实现，用于算法教学、方案比较和早期性能分析。

## 本期开发范围

1. 建立 rank、链路、拓扑、消息分片和通信步骤模型。
2. 支持 Scatter、Broadcast、AllGather 和 AllReduce。
3. 支持 Direct、Ring 和 Tree 算法模板。
4. 使用延迟与带宽参数建立确定性成本模型。
5. 验证数据来源、覆盖范围和最终接收状态等语义约束。
6. 提供命令行工具、结构化输出和算法比较结果。
7. 提供 2、4、8、12、16 rank 示例以及必要的单元测试。
8. 提供完整 README、架构说明与可复现演示。

## 技术方案

项目以统一的调度中间表示描述每一轮中的发送方、接收方、数据分片及依赖关系。算法生成器把集体通信操作转换为确定性步骤；语义检查器验证调度结果；成本估算器根据固定延迟、有效带宽和关键路径计算预测时间。所有核心模块使用 MoonBit 实现，并优先保持纯函数、确定性结果和跨后端可测试性。

## 项目特色

- MoonBit 原生实现，可作为生态中的基础算法与仿真组件。
- 无需专用硬件即可复现和比较集体通信算法。
- 同时关注算法语义正确性与性能估算。
- 模块边界清晰，可继续扩展 ReduceScatter、分层拓扑、链路争用和自动算法选择。

## 开源与 AI 使用说明

项目计划采用 Apache-2.0 许可证。开发过程中使用 OpenAI Codex 辅助接口设计、代码实现、测试和文档编写；项目目标、算法选择、代码审核与最终质量由参赛者负责。项目仅参考公开资料中的通用算法思想，不使用此前竞赛的专有代码或未授权实现。相关参考资料将在 README 中逐项标注。

一个公开、可构建、可测试的 MoonBit 仓库；一个可直接运行的命令行演示；覆盖核心算法和边界条件的测试；示例配置、输出结果、设计文档与后续路线图。
